# 外高桥货代版式识别

先按单据内容、抬头和字段标签识别货代，不以文件名决定业务字段。版式规则只用于定位，任何编号、金额或商品行仍须由单据标签和同票交叉证据确认。

| 货代 / 场景 | 常见材料与定位提示 | 提取边界 |
|---|---|---|
| DHL 快件 | DHL 运单 / 报关回执与 Commercial Invoice 通常分开；优先带 `AWB`、`Waybill` 或运单语义的编号。 | 不把客户参考号、DHL 内部处理号当作原始运单号；发票行仅来自商业发票。 |
| DHL 普货 | DGF 空运单与 Commercial Invoice 通常分开；在空运单中区分 `MAWB`、`HAWB` 和货运代理参考号。 | 只有能与本票收发货方和发票交叉确认的 HAWB/运单才写入 header。 |
| DSV 普货 | HAWB 正本 / Consignee 副本与发票可能是独立 PDF；优先读取明确标注 `HAWB No.` 的字段。 | 不因 `SIN...` 这类号码外观直接推断字段，需有 HAWB/运单标签或同票证据。 |
| FedEx 快件 | 运单页常有 Tracking / Air Waybill，商业发票可能独立出现。 | Tracking / 运单号仅在字段标签或同票证据明确时写入；不要把发票号替代为运单号。 |
| UPS 快件 / 普货 | UPS 运单号常以 `1Z` 开头，普货材料可能含多张商业发票、多个 PO/DN。 | 以运单页标签判定运单号；同一已确认运单下的多发票按材料顺序归集，不跨票合并。 |
| 康捷空普货 | 空运单、商业发票和 Tracking 可能分散；优先在空运单中找 `HAWB` / `Air Waybill` 标注。 | 货代参考号、航班号、件数和总重量不能替代原始运单号或商品行事实。 |

不同材料出现冲突、票次无法唯一归集，或版式无法证明字段含义时，保留已证实值并提交 `input_problems`，不要按号码长度、文件名或货代惯例猜测。
